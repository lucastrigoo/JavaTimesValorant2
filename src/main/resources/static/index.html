Mapeamento dos Endpoints Java Spring Boot & Fluxo HTTP

Este painel detalha os 4 métodos HTTP implementados no TimeController.java e integrados via fetch() no app.js, pronto para consulta durante a apresentação:

GET /time?nome={nome}

Objetivo: Consulta um time específico pelo nome.
Parâmetro: @RequestParam String nome
Retorno: 200 OK com JSON do objeto Time.

POST /time

Objetivo: Registra um novo time no banco de dados.
Header: Content-Type: application/json
Body: JSON serializado com { nome, tier, starPlayer, internacionais }.
Retorno: 200 OK (Void).

PUT /time?id={id}

Objetivo: Atualiza os dados de um time existente pelo ID.
Parâmetros: @RequestParam Integer id e @RequestBody Time time.
Retorno: 200 OK (Void).

DELETE /time?nome={nome}

Objetivo: Remove o registro do time pelo nome.
Parâmetro: @RequestParam String nome.
Retorno: 200 OK (Void).
